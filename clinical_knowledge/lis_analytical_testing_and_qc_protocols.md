# Clinical Biochemistry, Hematology & Analytical Quality Control Protocols

## 1. Overview
This protocol defines analytical testing parameters, standard clinical reference ranges, auto-calculation formulas, and daily quality control (QC) procedures for the HIMES laboratory modules.

## 2. Clinical Biochemistry Profiles & Reference Ranges (Adults)

### A. Liver Function Tests (LFT)
- **Total Bilirubin**: 0.2 - 1.2 mg/dL (3.4 - 20.5 µmol/L)
- **Direct (Conjugated) Bilirubin**: 0.0 - 0.3 mg/dL (0.0 - 5.1 µmol/L)
- **Indirect (Unconjugated) Bilirubin**: 0.2 - 0.8 mg/dL (Auto-calculated: Total - Direct)
- **Aspartate Aminotransferase (AST / SGOT)**: 10 - 40 U/L
- **Alanine Aminotransferase (ALT / SGPT)**: 7 - 56 U/L
- **Alkaline Phosphatase (ALP)**: 44 - 147 U/L
- **Gamma-Glutamyl Transferase (GGT)**: 9 - 48 U/L (Female: 9 - 36 U/L, Male: 11 - 50 U/L)
- **Total Protein**: 6.4 - 8.3 g/dL
- **Albumin**: 3.5 - 5.0 g/dL
- **Globulin**: 2.0 - 3.5 g/dL (Auto-calculated: Total Protein - Albumin)
- **A/G Ratio**: 1.1 - 2.2 (Auto-calculated: Albumin / Globulin)

### B. Renal Function Tests (RFT / KFT) & Electrolytes
- **Blood Urea Nitrogen (BUN)**: 7 - 20 mg/dL (2.5 - 7.1 mmol/L)
- **Serum Urea**: 15 - 45 mg/dL
- **Serum Creatinine**: Male: 0.7 - 1.3 mg/dL (62 - 115 µmol/L), Female: 0.5 - 1.1 mg/dL (44 - 97 µmol/L)
- **Estimated GFR (eGFR, CKD-EPI 2021 formula)**: >= 90 mL/min/1.73m² (Normal renal function)
- **Serum Uric Acid**: Male: 3.5 - 7.2 mg/dL, Female: 2.6 - 6.0 mg/dL
- **Sodium ($Na^+$)**: 135 - 145 mmol/L
- **Potassium ($K^+$)**: 3.5 - 5.1 mmol/L
- **Chloride ($Cl^-$)**: 98 - 107 mmol/L
- **Bicarbonate / Total $CO_2$**: 22 - 29 mmol/L
- **Serum Anion Gap**: 8 - 16 mmol/L (Auto-calculated: $(Na^+) - (Cl^- + HCO_3^-)$)
- **Total Calcium**: 8.5 - 10.5 mg/dL (2.15 - 2.55 mmol/L)
- **Corrected Calcium**: Auto-calculated: $\text{Total Calcium} + 0.8 \times (4.0 - \text{Albumin})$
- **Inorganic Phosphorus**: 2.5 - 4.5 mg/dL (0.81 - 1.45 mmol/L)
- **Magnesium**: 1.7 - 2.4 mg/dL (0.70 - 1.00 mmol/L)

### C. Lipid Profile (Fasting 10-12 hours)
- **Total Cholesterol**: Desirable: < 200 mg/dL, Borderline: 200 - 239 mg/dL, High: >= 240 mg/dL
- **Triglycerides**: Normal: < 150 mg/dL, Borderline: 150 - 199 mg/dL, High: 200 - 499 mg/dL, Very High: >= 500 mg/dL
- **HDL Cholesterol**: Male: > 40 mg/dL, Female: > 50 mg/dL (Protective: >= 60 mg/dL)
- **LDL Cholesterol (Calculated via Friedewald if TG < 400)**: $\text{Total Chol} - \text{HDL} - (\text{TG} / 5)$. Optimal: < 100 mg/dL (< 70 mg/dL in high ASCVD risk).
- **VLDL Cholesterol**: 5 - 30 mg/dL ($\text{TG} / 5$)
- **Non-HDL Cholesterol**: $\text{Total Chol} - \text{HDL}$ (Target: < 130 mg/dL)

### D. Glycemic Monitoring & Cardiac Biomarkers
- **Fasting Blood Sugar (FBS)**: Normal: 70 - 99 mg/dL, Impaired Fasting Glucose: 100 - 125 mg/dL, Diabetic: >= 126 mg/dL
- **Post-Prandial Blood Sugar (PPBS, 2h)**: Normal: < 140 mg/dL, Impaired: 140 - 199 mg/dL, Diabetic: >= 200 mg/dL
- **Glycated Hemoglobin (HbA1c)**: Normal: < 5.7%, Prediabetes: 5.7 - 6.4%, Diabetes: >= 6.5% (Treatment Target: < 7.0%)
- **High-Sensitivity Cardiac Troponin I (hs-cTnI)**: Male: < 34 ng/L, Female: < 16 ng/L (99th percentile cutoff for myocardial injury)
- **High-Sensitivity Cardiac Troponin T (hs-cTnT)**: < 14 ng/L
- **NT-proBNP**: < 125 pg/mL (< 75 yrs: < 125 pg/mL; >= 75 yrs: < 450 pg/mL)

## 3. Hematology & Coagulation Reference Ranges

### A. Complete Blood Count (CBC / FBC with 5-Part Differential)
- **Hemoglobin (Hb)**: Male: 13.5 - 17.5 g/dL, Female: 12.0 - 15.5 g/dL (Pregnancy: >= 11.0 g/dL)
- **RBC Count**: Male: 4.5 - 5.9 x $10^{12}$/L, Female: 4.0 - 5.2 x $10^{12}$/L
- **Hematocrit (PCV)**: Male: 41 - 50%, Female: 36 - 46%
- **Mean Corpuscular Volume (MCV)**: 80 - 100 fL (Microcytic: <80, Normocytic: 80-100, Macrocytic: >100)
- **Mean Corpuscular Hemoglobin (MCH)**: 27 - 33 pg
- **MCHC**: 32 - 36 g/dL
- **Red Cell Distribution Width (RDW-CV)**: 11.5 - 14.5%
- **Total White Blood Cell (WBC)**: 4,000 - 11,000 /µL ($4.0 - 11.0 \times 10^9$/L)
- **Differential Count**:
  * *Neutrophils*: 40 - 70% (Absolute: 1,500 - 7,500 /µL)
  * *Lymphocytes*: 20 - 40% (Absolute: 1,000 - 4,000 /µL)
  * *Monocytes*: 2 - 8% (Absolute: 200 - 800 /µL)
  * *Eosinophils*: 1 - 4% (Absolute: 50 - 500 /µL)
  * *Basophils*: 0.5 - 1.0% (Absolute: 20 - 100 /µL)
- **Platelet Count**: 150,000 - 450,000 /µL ($150 - 450 \times 10^9$/L)
- **Mean Platelet Volume (MPV)**: 7.5 - 11.5 fL
- **Erythrocyte Sedimentation Rate (ESR - Westergren)**: Male < 50y: <= 15 mm/hr, Male >= 50y: <= 20 mm/hr; Female < 50y: <= 20 mm/hr, Female >= 50y: <= 30 mm/hr

### B. Coagulation Profile
- **Prothrombin Time (PT)**: 11.0 - 13.5 seconds
- **International Normalized Ratio (INR)**: Normal: 0.8 - 1.2; Therapeutic (Warfarin / AF / DVT): 2.0 - 3.0; Mechanical Heart Valve: 2.5 - 3.5
- **Activated Partial Thromboplastin Time (APTT)**: 25 - 35 seconds (Therapeutic Unfractionated Heparin: 1.5 - 2.5 x Control)
- **Fibrinogen**: 200 - 400 mg/dL (2.0 - 4.0 g/L)
- **D-Dimer**: < 0.50 µg/mL FEU (Fibrinogen Equivalent Units)

## 4. Internal Quality Control (IQC) & Westgard Multirule Decision Algorithm
HIMES requires 2 or 3 levels of QC materials run every 24 hours (and after calibration/maintenance) on all automated analyzers.

### Westgard Rules Evaluation:
1. **$1_{2s}$ (Warning Rule)**: 1 QC observation exceeds $\text{Mean} \pm 2SD$. Accept run, but inspect $1_{3s}$ or systematic drift.
2. **$1_{3s}$ (Random Error - REJECT RUN)**: 1 QC observation exceeds $\text{Mean} \pm 3SD$. Immediate run rejection.
3. **$2_{2s}$ (Systematic Error - REJECT RUN)**: 2 consecutive QC observations exceed $\text{Mean} + 2SD$ or $\text{Mean} - 2SD$ (same level or across 2 levels).
4. **$R_{4s}$ (Random Error - REJECT RUN)**: Difference between two QC measurements in the same run exceeds $4SD$ (e.g., Level 1 is $+2.2SD$ and Level 2 is $-2.1SD$).
5. **$4_{1s}$ (Systematic Error - REJECT RUN)**: 4 consecutive QC measurements exceed $\text{Mean} + 1SD$ or $\text{Mean} - 1SD$.
6. **$10_x$ (Systematic Error - REJECT RUN)**: 10 consecutive QC measurements fall on the same side of the Mean.

### Corrective Action for QC Failure:
- Halt testing immediately in HIMES LIS for that parameter.
- Re-run fresh aliquot of QC; check reagent lots, calibrations, and analyzer fluidics.
- Never report patient results when QC is out of statistical control.
