# Code Blue and Rapid Response Team Standard Operating Procedure

## 1. Code Blue Activation
Dial internal emergency extension **3333** or press the red Code Blue wall button immediately upon discovering:
- Unresponsive patient with no pulse or abnormal/agonal breathing.
- Sudden cardiac collapse.

## 2. Code Blue Team Roles & Composition
- **Team Leader (Emergency Physician / Intensivist)**: Directs resuscitation, commands drug administration, decides on defibrillation and airway management.
- **Airway Manager (Anesthesiologist / Senior Resident)**: Manages bag-valve-mask ventilation, performs endotracheal intubation, verifies capnography.
- **Compressor (Nurse / Staff)**: Delivers high-quality chest compressions at 100-120 bpm, depth 5-6 cm, rotating every 2 minutes.
- **Defibrillator / Monitor Operator**: Applies defibrillator pads, analyzes rhythm, delivers shocks (Biphasic 200J).
- **Medication Nurse**: Prepares and administers ACLS drugs (Epinephrine 1mg IV every 3-5 mins, Amiodarone 300mg IV for refractory VF/pVT).
- **Recorder / Timer**: Records exact timestamps of interventions, rhythm checks, and drug doses.

## 3. Post-Resuscitation Care
Immediate 12-lead ECG, targeted temperature management (32°C - 36°C) for comatose post-ROSC patients, immediate arterial blood gas, and transfer to ICU.
